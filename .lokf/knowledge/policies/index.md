# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: whoever submits owns the contribution, an element says what the publication says, a rule states only what the publication states, a mapping is read at its source, and no commit carries an AI co-authorship trailer.
* [Security policy](security-policy.md) - How to report a vulnerability in this repository, by GitHub's private reporting, what executes here and what holds each surface. A problem in NIST's own text belongs with NIST.
* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and the schema under Apache-2.0, the bundle under CC BY 4.0, and the publication under NIST's statement, which allows reprints worldwide with its citation. No endorsement by NIST is implied.
